## Требования

- **macOS 14.4 или новее.** Захват системного звука использует Core Audio process tap, которого в более ранних версиях нет. Установщик пускает и на 14.0, но запись системной дорожки там не заработает.
- **Свободное место** — от 2 до 7 ГБ под модели, в зависимости от пресета, плюс место под аудио записей.
- Apple Silicon или Intel.

Linux и Windows не поддерживаются: захват аудио и локальный движок оставлены за
trait-заглушками (ограничения R4 и R9). Это принятое ограничение MVP, а не баг.

## Скачать

:::caution[Публичных выпусков пока нет]
Первый релиз не опубликован: он ждёт генерации ключа подписи обновлений. До этого момента
приложение ставится [сборкой из исходников](#сборка-из-исходников) — код открыт, и это
единственный честный способ его получить.
:::

Когда выпуски появятся: взять последний `.dmg` со страницы
[Releases](https://github.com/zdllucky/wotold/releases), открыть и перетащить Wotold в
Applications.

## Первый запуск: предупреждение Gatekeeper

Сборка **не нотаризована в Apple** — это осознанное решение на время MVP (ограничение R6),
а не признак того, что с файлом что-то не так. macOS откажется открыть приложение с первого
раза.

Как разрешить: **Системные настройки → Конфиденциальность и безопасность** → внизу будет
сообщение о заблокированном Wotold → **«Открыть всё равно»**.

Если предпочитаешь не полагаться на чужую подпись — [собери из исходников](#сборка-из-исходников),
код открыт.

## Что приложение попросит

**Имя и роль.** Нужно, чтобы понимать, кто говорит на твоей дорожке: микрофон — всегда
владелец устройства.

**Микрофон.** Твоя дорожка записи.

**Запись экрана.** Требуется macOS для доступа к системному звуку через ScreenCaptureKit.
Wotold **не сохраняет кадры и не делает скриншотов** — из API берётся только аудио. Проверить
это можно в исходниках, разрешение запрашивается только ради звуковой дорожки.

## Модели

При первом включении Wotold скачивает модели с HuggingFace (одну — из релизов sherpa-onnx на
GitHub). Дальше обработка идёт офлайн; в сеть приложение ходит только за проверкой новой
версии при запуске.

| Пресет | Размер | Чем отличается |
|---|---|---|
| **Light** | ~2 ГБ | Быстрее всех, заметно ниже качество распознавания и саммари |
| **Balanced** | ~4 ГБ | Компромисс по умолчанию |
| **Quality** | ~7 ГБ | Лучшее качество, дольше обработка и сильнее нагрев |

Пресет меняется в **Настройки → Обработка**. Модели при смене пресета автоматически не
удаляются — управление занятым местом вынесено в отдельный экран хранилища, чтобы
приложение не стирало гигабайты за спиной у пользователя (ограничение R12-bis).

Слабое железо не блокирует запуск: проба рекомендует Light и предупреждает, но выбор
остаётся за тобой (R13).

## Первая запись

1. На главном экране — **«Начать запись»** или `⌘⇧R`.
2. **«Стоп»** по окончании. Начнётся локальная обработка.
3. Прогресс виден в карточке звонка: распознавание, диаризация, саммари.

Обработка занимает минуты, а не секунды: STT и LLM считаются на твоём процессоре. Длинная
запись режется на части и обрабатывается по мере готовности.

## Сборка из исходников

```bash
git clone https://github.com/zdllucky/wotold.git
cd wotold
pnpm install
pnpm tauri dev
```

Нужны Node.js ≥ 20.18, pnpm ≥ 10, Rust stable и Tauri CLI 2
(`cargo install tauri-cli --version "^2"`). Подробности — в
[CONTRIBUTING.md](https://github.com/zdllucky/wotold/blob/main/CONTRIBUTING.md).

## Обновления

Приложение проверяет наличие новой версии при запуске — это анонимный запрос к GitHub без
твоих данных.

Само обновление пока **не устанавливается**: ключ подписи ещё не сгенерирован, и проверка
подписи закономерно не проходит. До появления ключа новую версию нужно скачивать вручную.
