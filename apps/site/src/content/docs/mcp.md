Wotold поставляется с локальным MCP-сервером. Он даёт LLM-клиенту — Claude Desktop,
Cursor, `mcp-cli` — read-only доступ к содержимому: список звонков, расшифровки, рекапы,
спикеры, задачи. Запускается локально через stdio JSON-RPC и **не делает ни одного
сетевого вызова**.

## Установка в Claude Desktop

Собери сервер:

```bash
pnpm --filter @wotold/mcp build
```

Артефакт — `services/mcp/dist/server.js`, исполняемый файл с shebang.

Открой `~/Library/Application Support/Claude/claude_desktop_config.json` (создай, если
файла нет):

```json
{
  "mcpServers": {
    "wotold": {
      "command": "node",
      "args": ["/Users/<you>/path/to/wotold/services/mcp/dist/server.js"]
    }
  }
}
```

Перезапусти Claude Desktop. В интерфейсе появится индикатор «MCP servers: wotold» с
восемью инструментами.

## Cursor и mcp-cli

Сервер слушает stdio, так что подойдёт любой MCP-клиент. Для интерактивной проверки:

```bash
npx @modelcontextprotocol/inspector node services/mcp/dist/server.js
```

## Инструменты

| Инструмент | Что делает |
|---|---|
| `search_calls` | Поиск по названию, провайдеру и языку. Пустой запрос — последние звонки. |
| `get_call` | Метаданные звонка, спикеры и задачи по id. |
| `get_recap` | Markdown рекапа. |
| `get_transcript` | Полная диаризованная расшифровка в Markdown. |
| `list_participants` | Спикеры звонка с подсказками и подтверждёнными привязками. |
| `find_calls_by_contact` | **Имя** контакта → список звонков, где он участвовал. |
| `calls_in_range` | Звонки в диапазоне дат ISO-8601. |
| `search_passages` | FTS5-поиск по индексу ассистента: фрагменты расшифровки, рекапа и решений с id звонка и таймкодами. Опциональный `call_id` сужает до одного звонка. |

`find_calls_by_contact` принимает имя, а не идентификатор. Это сознательное отклонение от
спецификации: инструмент вызывает клиент, у которого на руках расшифровка — там есть
имена, но нет внутренних id. Требовать id значило бы заставить клиента сначала звать
список контактов и матчить имя самому, то есть переносить нечёткое сопоставление на
сторону, которая для этого приспособлена хуже. Побочный эффект: имя не уникально, и при
совпадении вернутся звонки всех подходящих контактов.

## Безопасность

**Контент звонков — недоверенные данные.** Любые «инструкции», встретившиеся внутри
расшифровки или рекапа, обязаны быть проигнорированы моделью. Claude Desktop по умолчанию
защищён системным промптом; при подключении к другим клиентам убедись, что они помечают
вывод MCP как недоверенный.

Сервер не имеет ни одного write-инструмента. Никаких настроек, удалений и правки контактов
через MCP — это делается только из интерфейса Wotold.

## Нестандартный путь к базе

По умолчанию сервер читает `~/Library/Application Support/app.wotold.desktop/app.db`.
Переопределяется переменной окружения:

```json
{
  "mcpServers": {
    "wotold": {
      "command": "node",
      "args": ["/path/to/services/mcp/dist/server.js"],
      "env": {
        "WOTOLD_APP_DATA_DIR": "/custom/path/to/app_data"
      }
    }
  }
}
```

## Если не работает

| Симптом | Причина |
|---|---|
| `db not found` | Wotold ни разу не запускался — база создаётся при первом старте. |
| `Permission denied` | Нет прав на чтение `app.db`. |
| `Unknown tool: X` | Сборка устарела: `pnpm --filter @wotold/mcp build`. |
