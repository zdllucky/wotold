## Что нужно

macOS 14.2+, Node.js ≥ 20.18, pnpm ≥ 10, Rust stable и Tauri CLI 2. Разработка возможна
только на macOS: захват аудио и локальный движок за пределами её не реализованы.

```bash
git clone https://github.com/zdllucky/wotold.git
cd wotold
pnpm install
pnpm tauri dev
```

## Чем этот репозиторий отличается от обычного

Несколько правил проверяются механически, и PR, который их игнорирует, не пройдёт.

**Дизайн-гейт.** Любая правка `.tsx` или `.css` начинается с чтения канона и заканчивается
alignment-блоком в описании PR. Сырые hex и `oklch()` вне файлов токенов — блокер. Красный
цвет зарезервирован под запись и разрушающие действия, всё остальное — один графитовый
акцент.

**Клей тестируется первым.** Оркестрация — пайплайн, восстановление после сбоя, композиция
хуков — обязана получить happy-path и хотя бы один fail-path тест. Покрытие листьев за
покрытие клея не считается: все три известных прод-бага в конвейере обработки были именно
в клее, при педантично покрытых листьях.

**Регрессионный тест обязан падать до фикса.** Проверяется откатом фикса. Зелёный тест на
сломанном коде не доказывает ничего.

**i18n тотален.** Каждая строка, которую видит пользователь, идёт через `t()` и три локали
— включая нижние слои вроде текстов ошибок API.

**Деградация видима.** Любой путь «предупредить и продолжить», влияющий на результат
звонка, выставляет персистентный флаг, доступный интерфейсу. Только в лог — запрещено.

**Тяжёлый CPU не на async-исполнителе.** Кластеризация, ONNX-инференс, чтение WAV — внутри
`spawn_blocking`.

**Тесты без реального времени.** `sleep()` для синхронизации с фоновой задачей запрещён.

**800 строк на файл** считаются по итоговому файлу, а не по диффу.

## Ограничения, которые не надо «чинить»

Раздел 12 спецификации перечисляет решения, принятые сознательно: отсутствие
автоопределения звонка, отсутствие автопривязки спикеров, отсутствие Windows и Linux в MVP,
отсутствие нотаризации, модели вне установщика. PR, отменяющий одно из них, должен спорить
с исходным обоснованием, а не просто добавлять фичу.

Не уверен, входит ли идея в объём проекта, — заводи
[Discussion](https://github.com/zdllucky/wotold/discussions), а не PR.

## Коммиты и PR

Conventional Commits, `commitlint` в CI. **Заголовок PR подчиняется тому же правилу** —
`feat(assistant): …`, а не `M15: …`: заголовок в стиле майлстоуна валит проверку.

## Язык

Внутренняя документация написана по-русски — это рабочий язык проекта. Issues, pull
requests и контрибьюторские файлы — на английском. Английский принимается везде; языком
проект не отгораживается.
