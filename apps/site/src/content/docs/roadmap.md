## Работает

Ядро проходит полный путь от записи до ответа на вопрос:

- запись микрофона и системного звука раздельными дорожками;
- распознавание на устройстве, с разрезом длинных записей на части;
- диаризация и сопоставление голосов с контактами по отпечаткам;
- рекап, решения, открытые вопросы и задачи;
- RAG-ассистент по всему архиву с гибридным поиском и ссылками на фрагменты;
- локальный MCP-сервер для Claude — восемь read-only инструментов;
- автообновление: обязательные версии ставятся сами, обычные предлагаются тостом, запись при этом не прерывается никогда;
- редизайн интерфейса, светлая и тёмная темы, три локали.

Технический долг, найденный аудитом 2026-07 (пятьдесят пунктов), закрыт полностью.

## Отдельные фичи в очереди

Без обещаний по срокам — каждая требует собственного дизайна, а не «дозакрытия»:

- **Сохранённые подборки и экран поиска** — умные коллекции звонков с фильтрами.
- **Статистика инбокса** — сначала нужно понять, какие метрики вообще осмысленны на личном архиве.
- **Потоковая выдача ответа** ассистента вместо ожидания целиком; отсюда же взялся бы честный процент генерации.
- **Переформулировка вопроса** в диалоге — чтобы «а что он обещал?» понималось из предыдущей реплики.
- **Сводные отчёты по архиву** за период — не помещаются в контекстное окно, нужна отдельная схема.
- **Инкрементальная переобработка** — пересчитывать только упавшие части записи, а не всю.
- **Внешний Claude-коннектор** для ассистента со своими ключами — как явный opt-in.
- **LLM-подсказка спикеров** поверх кластеров: лишний проход модели по всей расшифровке на каждую запись стоит времени и нагрева, а подсказка по определению слабее биометрии.

## Решено не делать

Это ограничения, а не долг. Полный список с обоснованиями — раздел 12 спецификации.

| | Почему |
|---|---|
| Автоопределение «идёт звонок» | Эвристика ненадёжна; запись стартует только вручную |
| Автопривязка спикера к контакту | Биометрия ошибается, цена ошибки — чужие слова не тому человеку |
| Windows и Linux | Не в MVP; за trait оставлены заглушки |
| Нотаризация в Apple | Отложена; Gatekeeper предупреждает при первом запуске |
| Модели в установщике | Качаются по требованию, чтобы не раздувать дистрибутив |
| Субтитры в реальном времени | Распознавание offline-only |
| Автоудаление моделей при смене пресета | Приложение не стирает гигабайты за спиной у пользователя |

## Что нужно, чтобы двинуть отдельные пункты

Часть работы упирается не в код, а в отсутствующие данные:

- **Порог кластеризации голосов** нельзя менять без размеченного набора записей с известным числом говорящих — иначе это гадание.
- **Поведение эмбеддингов на коротких репликах** (меньше двух секунд) — открытый вопрос: модель обучена на окнах около пяти секунд.
- **Оценка «осталось примерно N минут»** требует накопленной статистики по пресетам, которая только начала собираться.
