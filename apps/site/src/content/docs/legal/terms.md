## 1. Предмет

1.1. Wotold — приложение для операционной системы macOS, осуществляющее запись разговоров и их
обработку на устройстве пользователя.

1.2. Серверная часть у продукта отсутствует. Учётная запись не создаётся, данные не передаются,
администрирование доступа не осуществляется.

1.3. Использование приложения означает согласие с настоящими условиями.

## 2. Отсутствие гарантий

2.1. Приложение предоставляется **«как есть»** (AS IS), без каких-либо гарантий, явно
выраженных либо подразумеваемых, включая гарантии пригодности для определённой цели,
отсутствия дефектов и ненарушения прав третьих лиц. Разделы 7 и 8
[Apache License 2.0](https://github.com/zdllucky/wotold/blob/main/LICENSE) применяются в
полном объёме.

2.2. **Приложение не следует использовать в качестве единственного средства фиксации
существенного разговора.** Продукт находится на ранней стадии развития; запись может не
начаться, прерваться либо оказаться неполной. При наличии повышенных требований к сохранности
записи рекомендуется дублирование иными средствами.

## 3. Отсутствие нотаризации

3.1. Готовые сборки не проходят процедуру нотаризации Apple. Данное обстоятельство является
принятым ограничением текущего этапа разработки.

3.2. При первом запуске операционная система выводит предупреждение; запуск требует явного
разрешения пользователя.

3.3. Пользователю следует учитывать, что установка приложения сопряжена с обходом штатной
проверки операционной системы. Загрузка допускается исключительно со
[страницы выпусков проекта](https://github.com/zdllucky/wotold/releases); альтернативой
является самостоятельная сборка из открытого исходного кода.

## 4. Обязанности пользователя

4.1. **Правомерность записи.** Во многих юрисдикциях запись разговора требует согласия всех его
участников. Приложение не уведомляет вторую сторону и не определяет применимую юрисдикцию.
Обязанность уведомить участников и получить их согласие возлагается на пользователя. См.
[уведомление о записи разговоров](../consent/).

4.2. **Данные третьих лиц.** Записи и расшифровки содержат персональные данные иных лиц. Их
хранение, использование и удаление относятся к сфере ответственности пользователя; приложение
предоставляет соответствующие технические средства (каскадное удаление, отзыв согласия на
обработку голосового образца).

4.3. **Биометрические данные.** Голосовые образцы в ряде правопорядков относятся к особой
категории персональных данных с усиленным режимом защиты. Соответствующая функция отключена по
умолчанию и активируется пользователем осознанно.

4.4. **Сохранность данных.** Резервное копирование осуществляется пользователем самостоятельно.
Данные размещаются в каталоге `~/Library/Application Support/app.wotold.desktop/`;
автоматическое резервное копирование приложением не производится.

## 5. Компоненты третьих лиц

5.1. Модели машинного обучения загружаются с сервиса HuggingFace и **не распространяются**
настоящим проектом.

5.2. Условия использования каждой модели устанавливаются её правообладателем; проверка таких
условий относится к сфере ответственности лица, осуществляющего загрузку. Перечень приведён в
файле [`NOTICE`](https://github.com/zdllucky/wotold/blob/main/NOTICE).

6.1. Обновления доставляются посредством встроенного механизма и снабжаются криптографической
подписью.

6.2. Разработка проекта может быть прекращена либо изменена без предварительного уведомления;
обязательства по поддержке не принимались.

6.3. Ранее установленное приложение сохраняет работоспособность: оно не требует соединения с
сервером и не может быть отключено дистанционно.
