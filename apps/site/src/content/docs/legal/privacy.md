**Редакция 0.3 от 23 июля 2026 года.** [Все правовые документы](../)

Wotold — приложение для записи, расшифровки и обобщения телефонных и онлайн-разговоров,
исполняемое на устройстве пользователя. Настоящая политика определяет состав обрабатываемых
данных, места их хранения, случаи передачи за пределы устройства и права пользователя в
отношении этих данных.

## 1. Основные положения

1.1. Обработка данных выполняется исключительно на устройстве пользователя. Приложение не
имеет серверной части, не создаёт учётных записей и не осуществляет облачного хранения.

1.2. Исходящие обращения к сети ограничены двумя случаями: загрузкой моделей машинного
обучения при первом использовании соответствующей функции и проверкой наличия обновления при
запуске приложения. Ни в одном из них не передаются пользовательские данные. Обработка
разговоров во всех случаях выполняется без обращения к сети.

1.3. Обработка биометрических данных (голосовых образцов) осуществляется исключительно при
наличии явно выраженного согласия пользователя, предоставляемого отдельно в отношении каждого
контакта, и не сопровождается передачей таких данных за пределы устройства.

1.4. Управление данными осуществляется средствами интерфейса приложения: удаление контакта,
удаление записи разговора с сопутствующими файлами, отзыв ранее предоставленного согласия.

1.5. Возможные будущие интеграции с внешними сервисами — подключение пользователем
собственного коннектора со своими ключами доступа — составляют отдельную функциональность,
активируемую исключительно по явному волеизъявлению пользователя. В текущей версии приложения
такая функциональность не реализована.

## 2. Состав обрабатываемых данных

| Категория | Место хранения | Содержание | Срок хранения |
|---|---|---|---|
| Аудиозаписи (`*.wav`) | `~/Library/Application Support/app.wotold.desktop/calls/<id>/` | Дорожка микрофона и дорожка системного звука в формате PCM | До удаления пользователем |
| База данных (`app.db`) | Тот же каталог | Метаданные разговоров, контакты, расшифровки, задачи, голосовые образцы (при наличии согласия), поисковый индекс | До удаления пользователем |
| Расшифровки и обобщения (`*.md`) | `calls/<id>/` | Расшифровка с разделением по участникам, обобщение, протокол, перечень задач | До удаления пользователем |
| Модели машинного обучения | Каталог моделей приложения | Модели распознавания речи, генерации текста, векторного представления, определения речевой активности и разделения дикторов | До удаления пользователем средствами интерфейса |

Перечисленные данные хранятся исключительно на устройстве пользователя.

## 3. Передача данных за пределы устройства

Приложение обращается к сети в двух случаях, перечисленных ниже. Иных исходящих соединений оно
не устанавливает.

### 3.1. Загрузка моделей

При первом использовании локального механизма обработки либо при изменении выбранного набора
моделей приложение загружает соответствующие файлы с сервиса HuggingFace. Одна модель —
векторное представление голоса (WeSpeaker) — загружается из состава выпусков проекта
sherpa-onnx, размещённых на GitHub.

При загрузке не передаются заголовки, содержащие пользовательские данные; используется
стандартный идентификатор клиента. К указанным передачам применяются политики
конфиденциальности [HuggingFace](https://huggingface.co/privacy) и
[GitHub](https://docs.github.com/site-policy/privacy-policies/github-privacy-statement).

После загрузки повторные обращения к сервисам моделей не производятся; обработка разговоров
выполняется автономно.

### 3.2. Проверка обновлений

При каждом запуске приложение запрашивает у GitHub файл-манифест с описанием последней
опубликованной версии по адресу `github.com/zdllucky/wotold/releases/`.

Указанный запрос представляет собой обычное получение общедоступного файла. Он не содержит
идентификаторов установки, сведений о разговорах, контактах либо иных пользовательских данных.
GitHub, как и любой сервер, фиксирует IP-адрес обращающегося; иных сведений о пользователе
передано не будет.

Отключение проверки обновлений в интерфейсе приложения на текущем этапе не предусмотрено;
данная возможность отмечена как подлежащая реализации.

### 3.3. Аудиозаписи и содержание разговоров

Аудиозаписи, расшифровки и обобщения **не передаются за пределы устройства ни при каких
обстоятельствах**. Распознавание речи, разделение дикторов, формирование обобщений и работа
ассистента выполняются локальными механизмами обработки.

### 3.4. Планируемые интеграции

Возможность подключения пользователем внешнего сервиса обработки с использованием
принадлежащих ему ключей доступа предполагается к реализации в качестве отдельной
функциональности. При её введении передача каких-либо данных за пределы устройства потребует
отдельного явно выраженного согласия пользователя с указанием состава передаваемых данных и
получателя. Хранение ключей доступа предусмотрено исключительно в системном хранилище учётных
данных операционной системы, без сохранения в базе данных приложения и в журналах событий.

## 4. Биометрические данные

4.1. При включении пользователем функции запоминания голоса в отношении конкретного контакта
приложение вычисляет векторное представление голоса на основании фрагмента аудиозаписи и
сохраняет его в локальной базе данных.

4.2. Указанное векторное представление:

- не передаётся за пределы устройства;
- используется исключительно для формирования предположений о личности участника при
  последующих разговорах;
- не влечёт автоматического сопоставления участника с контактом — такое сопоставление во всех
  случаях требует подтверждения пользователем;
- подлежит удалению средствами интерфейса приложения.

4.3. Функция запоминания голоса отключена по умолчанию.

## 5. Права пользователя

В соответствии со статьями 13–17 Общего регламента по защите данных (GDPR) пользователю
обеспечиваются следующие возможности.

**Доступ.** Все данные доступны через интерфейс приложения. Файлы аудиозаписей и база данных
находятся в каталоге `~/Library/Application Support/app.wotold.desktop/`.

**Удаление.** Удаление разговора влечёт удаление связанных аудиофайлов, записей базы данных и
голосовых образцов, полученных из этого разговора. Удаление контакта влечёт удаление всех
голосовых образцов данного контакта.

**Отзыв согласия.** Отключение функции запоминания голоса в карточке контакта.

**Переносимость.** Обобщения и расшифровки хранятся в формате Markdown в каталоге
`calls/<id>/` и могут быть скопированы пользователем самостоятельно.

**Полное удаление.** Удаление каталога `~/Library/Application Support/app.wotold.desktop/`.

Обращение к оператору для реализации перечисленных прав не требуется: все операции выполняются
пользователем самостоятельно на собственном устройстве.

## 6. Меры безопасности

6.1. Загрузка моделей осуществляется по защищённому соединению; целостность загруженных файлов
проверяется по контрольной сумме SHA-256. При несовпадении контрольной суммы загруженный файл
удаляется и в работу не принимается.

6.2. Обработка разговоров выполняется без обращения к сети.

6.2-бис. Механизм автоматического обновления предусматривает проверку криптографической
подписи выпуска. Открытый ключ включён в состав приложения. До публикации первого
подписанного выпуска проверка завершается отказом и обновление не устанавливается; сетевой
запрос манифеста (пункт 3.2) при этом выполняется.

6.3. Ключи доступа планируемых внешних интеграций подлежат хранению исключительно в системном
хранилище учётных данных.

6.4. Сервер MCP предоставляет доступ в режиме чтения, не имеет функций записи и не осуществляет
сетевых обращений. Содержание разговоров обрабатывается как недоверенные данные с применением
мер защиты от внедрения инструкций.

## 7. Настоящий сайт

Сайт представляет собой статический набор файлов, размещённый на сервисе GitHub Pages. Сайт не
использует систему веб-аналитики, счётчики посещений, файлы cookie и сторонний исполняемый код;
шрифты предоставляются с того же домена.

Журналы обращений на уровне хостинга ведутся сервисом GitHub в соответствии с
[его политикой](https://docs.github.com/site-policy/privacy-policies/github-privacy-statement).

## 8. Изменение политики

Существенные изменения настоящей политики публикуются в данном разделе с изменением номера
редакции и указанием даты, а также отражаются в примечаниях к соответствующему выпуску
приложения.

## 9. Обращения
