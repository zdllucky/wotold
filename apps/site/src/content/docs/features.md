## Диаризация — разделение по голосам

Задача, ради которой всё затевалось. Существующие инструменты расшифровывают звонок сплошным
потоком без атрибуции: получается стена текста, по которой невозможно ни искать, ни собрать
осмысленный рекап — «кто именно это пообещал» из неё не достаётся.

Wotold пишет **микрофон и системный звук раздельными дорожками**. Твоя речь по построению
никогда не путается с чужой. Внутри системной дорожки голоса разделяет sherpa-onnx, и уже
поверх готовых кластеров работают рекап, поиск и ассистент.

## Голосовые отпечатки

Если разрешить это для конкретного контакта, Wotold вычисляет вектор голоса и в следующий
раз подсказывает: «возможно, это Иван».

Именно **подсказывает**. Автоматической привязки нет и не будет — это зафиксированное
ограничение (R2), а не недоделка. Биометрия ошибается, и цена ошибки здесь — чужие слова,
приписанные не тому человеку.

Отпечатки выключены по умолчанию, включаются отдельно по каждому контакту, живут только в
локальной базе и удаляются вместе с контактом.

## Ассистент по всему архиву

Локальный чат отвечает на вопросы по всей базе звонков: «что мы решили по срокам с Акме»,
«кто отвечает за макеты».

Поиск гибридный — лексический BM25 поверх FTS5 плюс семантический по эмбеддингам, результаты
объединяются алгоритмом RRF. Чисто ключевой поиск промахивается на синонимах и перефразировках;
вектор ловит смысл, но плывёт на точных формулировках. Вместе они закрывают дыры друг друга.

Ответ генерирует модель на устройстве и приводит **ссылки на конкретные фрагменты**
расшифровки. Если в архиве ответа нет, ассистент говорит об этом прямо, а не сочиняет.

## MCP-сервер для Claude

Локальный read-only сервер даёт Claude прямой доступ к расшифровкам: поиск, цитирование,
Q&A без копипаста. Восемь инструментов, ноль сетевых вызовов, ни одной операции записи —
изменить что-либо через MCP нельзя по устройству.

Настройка — на [отдельной странице](../mcp/).

## Саммари, решения, задачи

По окончании обработки локальная модель собирает рекап, список решений, открытые вопросы и
задачи с привязкой к ответственным.

Качество локальной модели **ниже облачной** — это честно указано в интерфейсе значком
уровня движка (R12). Рекап можно перегенерировать без повторного распознавания: результат
STT сохраняется отдельно.

## Движок целиком на устройстве

| Слой | Что используется |
|---|---|
| Захват аудио | Core Audio process tap через Swift-сайдкар |
| Распознавание | whisper.cpp |
| Диаризация и эмбеддинги голоса | sherpa-onnx |
| Саммари и ассистент | llama.cpp |
| Семантический поиск | multilingual-e5-small через ONNX Runtime |
| Хранилище | SQLite + Markdown-файлы |

Длинные записи режутся на десятиминутные части: так обработка идёт конвейером, и падение на
одном куске не уносит весь звонок.

## Чего Wotold не делает

Список короткий и осознанный:

- **не начинает запись сама** — только твоя кнопка (R3);
- **не присваивает спикеров контактам** без подтверждения (R2);
- **не записывает экран** — из ScreenCaptureKit берётся только звук;
- **не показывает субтитры в реальном времени** — распознавание offline-only (R11);
- **не работает на Windows и Linux** — заглушки за trait (R4, R9);
- **не бандлит модели в установщик** — качаются по требованию (R10).
