# TD-20 — эмпирика (whisper.cpp, macOS aarch64, 2026-07-27)

Бинарь: `binaries/wotold-whisper-aarch64-apple-darwin`, модели whisper-small.bin / whisper-medium.bin
из реальной инсталляции. Аргументы те же, что в проде (`--output-json-full`).

## Ключевое: `tokens[].p` уже есть в JSON, но выбрасывается при парсинге

`WhisperSegment` десериализует только `text` + `offsets`. Поле `tokens` с per-token `p`
приходит всегда и игнорируется. `TranscriptSegment.confidence: Option<f64>` существует в
контракте (`packages/contracts/src/transcript.ts:17`) и всегда `None`.

## Выводы

1. **Точность масштаба задачи.** Аудит утверждает «реальные короткие реплики вежливых
   концовок систематически теряются». Это преувеличение: whisper ставит пунктуацию на
   реальной речи, а exact-match идёт по голому слову — `'Thanks.'` не совпадает с `thanks`.
   Реально теряется только бесточечная форма. Воспроизведено на `"You"` → `'you'` @0.520.
2. **Вероятность разделяет ровно спорный случай.** Одна и та же строка `'you'`: реальная
   речь 0.520, тишина 0.135–0.191. Никакой позиционной эвристики для этого не нужно.
3. **Вероятность НЕ заменяет остальной фильтр.** Русские субтитр-credits с тишины идут с
   avg_p 0.805–0.934, шумовые loop'ы — 0.93. Substring-список, bracket-shape и
   repetition-машинерия обязаны остаться без изменений.
4. **Порог.** Худшая наблюдённая галлюцинация-филлер 0.191, слабейшая реальная речь 0.513.
   Геометрическая середина ≈ 0.31.
