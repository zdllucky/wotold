## Как работать с этим файлом

- **Одна задача TD-NN = одна сессия** по PDCA-воркфлоу W3 из [`../CLAUDE.md`](../CLAUDE.md): design gate (если UI) → plan → TDD → verify → `/code-review` → mark done.
- **Якоря дрейфуют.** `file:line` — подсказка, истина — файл + имя символа. Первым делом в сессии сверить якорь.
- **Порядок волн = приоритет по умолчанию.** Внутри волны задачи независимы, если не указано `→ после TD-NN`.
- **Метки:** `(S)` < 2ч · `(M)` полдня-день · `(L)` больше дня · `⚑` release-критично.
- **Закрытие:** `[x]` на месте + строка итога (что за тесты/проверка подтвердили). ID стабильны и не перенумеровываются; новые находки дописываются в конец своей волны.
- **Системные выводы** аудита оформлены не задачами, а правилами → [`../CLAUDE.md`](../CLAUDE.md) §«Инженерные правила». Продуктовые release-блокеры (LICENSE, consent-notice) → [`ROADMAP.md`](ROADMAP.md) §A.
