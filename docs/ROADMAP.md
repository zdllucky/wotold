## T · Авто-стоп по тишине + подрезка хвоста (2026-07-30)

> Вторая половина секции S. S закрыла **старт**: проба «микрофон занят + frontmost из whitelist» предлагает начать запись (`CallActivityProbe.swift` → `audio/call_detect.rs` → `SuggestBanner.tsx`, настройка default OFF). T закрывает **стоп**: забытая запись живёт часами, `duration_sec` считается по wall-clock, а chunked-пайплайн (default ON) каждые 10 минут гонит тишину через whisper и добирает галлюцинации в транскрипт и рекап.
>
> Новое ограничение паспорта — **R15** (§12): сигнал тишины только RMS, пауза тишиной не считается, подсказка фиксирована на 15 мин, стоп настраиваемый (30/60/120/never, default 30), рез только на авто-стопе, факт реза виден чипом.
>
> Решения владельца: сигнал — только RMS; «Продолжить» сбрасывает счётчик тишины (авто-стоп откладывается на полный интервал заново); подрезка — только при авто-стопе.

- [x] **T1** (M) `audio/silence_watch.rs` — чистый FSM: `on_sample/on_pause/on_resume/snooze` → `SuggestStop{silent_for_ms, auto_stop_at_ms}` / `AutoStop{trim_at_ms = silence_start + tail_pad}`. Гистерезис в обе стороны (одиночный щелчок не сбрасывает run, нужно ~1.5 с непрерывного звука); каждое событие выдаётся один раз на run. Пауза сбрасывает run — на паузе рекордеры делают `level.reset()`, тот же guard, что в `chunk_orchestrator.rs:211-215` (twin parity).
- [x] **T2** (M) Задача-обёртка `silence_watch::run(cfg, rms_rx, pause_rx, snooze_rx, stop_rx, on_event)` формой `chunk_orchestrator::run`; fan-out RMS из `run_dispatcher` в оба потребителя через новый `DispatcherFanout { orchestrator, silence_tx }` (watcher обязан работать и когда chunked выключен). Поле `silence_watch` в `AppState`, парный pause/resume-сигнал одним хелпером, команда `snooze_silence_watch`. Клей тестируется первым: happy-path + fail-path, без `sleep`.
- [x] **T3** (S) Настройки: `recording.silence_prompt` (bool, default ON) и `recording.silence_auto_stop` (`30|60|120|never`, default `30`) — KV-таблица, миграция не нужна; клампинг на границе как в `enable_call_detect`. Группа в `SettingsPage.tsx` рядом с «Авто-детект», i18n ×3.
- [x] **T4** (M) `audio/wav_trim.rs` — `trim_wav_tail(path, keep_ms)` потоково через hound, `.wav.tmpN` + `fs::rename` (схема `audio_merger::merge_track`), только внутри `spawn_blocking`. No-op на уже коротком файле, `Err` (не panic) на битом header.
- [x] **T5** (L) Авто-стоп: `stop_recording_inner(app, state, trim_at_ms: Option<u64>)` вынесен из команды (`None` = прежнее поведение байт-в-байт). При `Some`: длительность считается от точки реза вместо wall-clock, `calls.silence_trim_ms` (миграция 0027), degraded-флаг `auto_stopped_on_silence` в `packages/contracts/src/degraded.ts` + расшифровка ×3 + чип в шапке, событие `recording:auto_stopped`.
- [x] **T6** (M) Рез в пайплайне: шаг подрезки в `local_run.rs::transcribe_tracks` после chunked-merge и до сборки транскриптов (одна точка на оба пути, идемпотентно при reprocess и repin). `load_chunked_transcripts(pool, call_id, cutoff_ms)` — чанки за cutoff выбрасываются целиком, у пограничного сегменты обрезаются. Без этого рез бессмыслен: тихие чанки уже прошли whisper во время записи.

Заодно сняты русские литералы из `call_detect.rs` (нарушение правила 4) и старт из `SuggestBanner` проведён через consent-гейт `App.onStart`, который он обходил.

**Ревью (2026-07-30).** Многоагентный прогон упал на лимите сессии: из 24 агентов доехали два ревьюера, все верификаторы умерли, поэтому находки проверены вручную по коду. Восемь подтвердились и починены здесь же:

- **Гейт «слишком коротко» считал подрезанную длительность.** Получасовая запись с замьюченным микрофоном (RMS ноль с самого начала) подрезалась до 5 секунд, не проходила порог 30с и удалялась вместе со всем `calls/<id>/` — молча, без события и без следа в UI. Теперь гейт смотрит на wall-clock: признак случайного нажатия — что запись шла недолго, а не что в ней мало звука. `is_accidental_tap` + 4 теста.
- **Точка реза уезжала на паузах.** `silence_trim_ms` — wall-clock (паузы включены), а WAV на паузе не растёт. После часовой паузы рез оказывался за концом файла, `trim_wav_tail` возвращал «резать нечего», и хвост оставался — при том что чип обещал обратное. Файлам теперь отдаётся `calls.duration_sec` (та же величина за вычетом пауз), транскрипту — wall-clock точка, которой размечены чанки.
- **`WOTOLD_SILENCE_SCALE` жил в релизной сборке.** Переменная, забытая в профиле оболочки, ускоряла авто-стоп в тысячи раз. Теперь только `debug_assertions`.
- **`never`, выставленный во время звонка, не спасал текущую запись** — конфиг читался один раз на старте. Настройка перечитывается в момент решения: R14 обещает полный opt-out, и обещание должно работать тогда, когда его дали.
- **Чип утверждал, что хвост отрезан, даже когда рез не удался.** Формулировка во всех трёх локалях сведена к факту «остановлена автоматически после тишины».
- **Уведомления замерзали на локали первого рендера** (слушатели с пустыми deps держали старый `t`) — в обоих баннерах.
- **Баннер продолжал обещать авто-стоп после паузы**, хотя наблюдатель на паузе сбрасывает счётчик. Снимается на любом не-`recording` статусе.
- **Кнопка «Остановить» обходила общий флоу стопа** — ровно тот же обход, что чинили у старта: ни тоста «слишком коротко», ни перехода на звонок. Проведена через `App.onStop`.

Не отревьюено: линзы correctness и rules — их агенты не запустились.

Реализовано с отклонениями от плана, все в сторону упрощения:

- **`auto_stop_at_ms` → `auto_stop_in_ms`.** Абсолютный дедлайн фронт всё равно вычитал бы из точки отсчёта, которой у него нет; отдаём остаток.
- **Флаг `auto_stopped_on_silence` ставит пайплайн, а не стоп.** `clear_degraded_flags` чистит флаги на reprocess — выставленный на стопе исчез бы после первой же переобработки, хотя рез никуда не делся.
- **Три новых модуля вместо двух** (`silence_watch/{mod,task}`, `transcript_cutoff`): гейт 800 строк считает итоговый файл, и `chunk_assembly` с `silence_watch` в него упирались.
- **Уведомления через Rust-команду**, а не `@tauri-apps/plugin-notification`: плагин уже есть в Rust, а строки обязаны идти через `t()`.

Вне объёма T (следствие «резать только на авто-стопе»): skip STT для полностью тихих чанков во время записи. Впустую сожжённый whisper остаётся, но результат корректен — T6 выбрасывает эти сегменты из транскрипта.
