## Зафиксированные решения

- **`ai-field` — единственный цветной бренд-элемент ассистента.** Анимированное
  conic-градиентное кольцо 1px из палитры голосов БЕЗ тёплых тонов:
  `sp1 → sp5 → sp2 → sp4 → sp1`, оборот 7s linear, hover 2.8s. Реализация:
  `border: transparent` + два background-слоя (padding-box заливка `--ai-bg`,
  border-box conic от `@property --ai-a`). Применяется **ровно к трём полям**:
  сайдбар «Найти или спросить» (`ai-field--panel`), контейнер ⌘K-палитры,
  композер вопроса (раздел + звонок). Больше никуда.
- Графит-моно НЕ нарушается: логотип, кнопки, навигация не перекрашиваются.
  Красный — только запись/деструктив. `--sp1…5` — только голоса/аватары/спикеры
  во фрагментах «Контекста поиска».
- Лёгкий `fade-up` на появление сообщений. Больше никакой анимации.
  `prefers-reduced-motion: reduce` → `ai-field` без анимации (статичное кольцо).
- Тексты — деловой регистр, дословно из мока, без разговорности и глаголов
  1-го лица процесса. Тех-детали (токены, окно) — только в mono-строке
  «Контекста поиска». Все строки через i18n `assistant.*` ×3 локали.
- Строка списка чатов — `div role="button"`, НЕ вложенные `<button>` (внутри trash-IconBtn).
- Light + dark обязательны на всех новых поверхностях.

## Acceptance (из `01-SPEC.md` §8)

- [ ] Раздел «Ассистент» в навигации (иконка `chat`) + мини-рейле + ⌘K.
- [ ] Индекс: только ready; чип статистики с корректной суммой длительностей.
- [ ] Новый чат на каждый диалог; список чатов: группировка, удаление, активность.
- [ ] Классификация: генеративный запрос → отказ без retrieval.
- [ ] Ответ: источники-чипы с переходами (seek / открыть звонок).
- [ ] «Контекст поиска»: фрагменты + счётчик токенов; у отказа отсутствует.
- [ ] «Не найдено» честное; в звонке — эскалация «Искать во всех звонках».
- [ ] Тред звонка персистится и не смешивается между звонками.
- [ ] Copy / «Скопировать с источниками» работают (clipboard rejection ловится).
- [ ] ⌘K fallback «Спросить ассистента» с Enter.
- [ ] `ai-field` анимируется, темы light/dark, ничего больше не перекрашено.
- [ ] Консоль чистая: без вложенных `<button>`, без unhandled rejections.
