# Wotold · Хэндофф — раздел «Ассистент» (RAG-поиск по звонкам)

Пакет для имплементации в десктоп-приложении (Tauri 2). Внутри — работающий мок
(HTML + Babel-in-browser React) и спецификация бизнес-логики.

## Как посмотреть мок
Открыть `Wotold v2 — Ассистент.html` любым статик-сервером (файлы соседние). Всё
интерактивно: раздел «Ассистент», чаты, ⌘K, ассистент внутри звонка «Синхрон по пилоту».

## Файлы
- `01-SPEC.md` — **главное**: бизнес-логика, UI-контракты, acceptance checklist.
- `Wotold v2 — Ассистент.html` — точка входа мока (порядок загрузки скриптов = порядок зависимостей).
- `wk2-assistant.jsx` — раздел «Ассистент»: движок ответа `WK_AS_ANSWER`, хранилище чатов, `AnswerMsg` (ответ + источники + контекст + действия), `AssistantView`.
- `wk2-screens.jsx` — форк экранов: ассистент внутри звонка (тред на звонок, кросс-звонковые источники, эскалация).
- `wk2-app.jsx` — форк шелла: пункт навигации, роутинг, ⌘K с fallback «Спросить ассистента», поле «Найти или спросить».
- `wk2.css` — стили раздела + `ai-field` (анимированный градиент).
- Остальное (`uikit*`, `wk-data.jsx`, `wk-inbox.jsx`, `wk-extra.jsx`, `wk-settings.jsx`, `wk-designsystem.jsx`) — базовый UI-кит и данные v2, без изменений (в `uikit-icons.jsx` добавлена иконка `chat`).

Мок = источник истины по вёрстке и состояниям; спека = источник истины по логике.
