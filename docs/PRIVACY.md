# Политика конфиденциальности — Wotold

_Версия: 0.3 (переход на local-only, 2026-07-23)_

Wotold — десктоп-приложение для локальной записи звонков с транскрипцией и саммари. Этот документ описывает, какие данные мы обрабатываем, где они хранятся, и какие права есть у пользователя. Документ заменит/дополнится в момент первого публичного релиза.

## TL;DR

- **Полностью локальный движок.** Аудио, транскрипты, рекап-саммари и поиск считаются на устройстве пользователя. Никаких серверов, аккаунтов и облачной обработки.
- **Единственный сетевой поток** — первичное скачивание моделей с HuggingFace при первом включении. После скачивания приложение работает офлайн.
- Биометрические данные (voice samples / embeddings) — **только с явного opt-in** для каждого контакта и без передачи куда-либо за пределы устройства.
- Управление данными — полностью в UI приложения: удалить контакт, удалить звонок (каскадно с аудио и семплами), отозвать согласия.
- Будущие внешние интеграции (подключение собственного Claude-коннектора со своими ключами) — планируются как отдельная опциональная фаза; они будут явным opt-in и в текущей сборке не задействованы.

## Какие данные мы собираем

| Категория | Где хранится | Что внутри | TTL |
|---|---|---|---|
| Аудиозаписи (`*.wav`) | `~/Library/Application Support/app.wotold.desktop/calls/<id>/` | Микрофон + системное аудио, raw PCM | Пока пользователь не удалит |
| База данных (`app.db`) | то же | Метаданные звонков, контакты, расшифровки, action_items, voice samples (если opt-in), индекс ассистента | то же |
| Транскрипты и рекапы (`*.md`) | `calls/<id>/` | Диаризованная расшифровка, рекап + МоМ + задачи | Пока пользователь не удалит |
| Локальные модели | каталог моделей приложения | Whisper (STT), LLM (саммари/ассистент), эмбеддер, VAD, диаризация | Пока пользователь не удалит через storage UI |

Всё перечисленное хранится **только на устройстве**. Wotold не создаёт аккаунтов и не отправляет эти данные на какие-либо серверы.

## Какие данные передаются наружу

### Скачивание моделей (единственный сетевой поток)

При первом включении локального движка / выборе preset'а Wotold скачивает модели с HuggingFace:

- `https://huggingface.co/...` — Whisper модели для STT
- `https://huggingface.co/...` — LLM модели для саммари и ассистента
- `https://huggingface.co/...` — модель эмбеддера для семантического поиска, VAD и диаризация

Никаких заголовков с пользовательскими данными при скачивании не отправляется — только стандартный User-Agent. HuggingFace применяет свою политику: https://huggingface.co/privacy.

После скачивания модели остаются на диске; повторных вызовов нет, обработка звонков идёт полностью офлайн.

### Аудио и контент звонков

**Никогда не покидают устройство.** Транскрипция, диаризация, генерация саммари и работа ассистента выполняются локальными движками (whisper.cpp, sherpa-onnx, llama.cpp). Ни аудио, ни транскрипты, ни рекапы не отправляются ни на какие сторонние API.

### Будущие внешние интеграции (planned)

Опциональная интеграция «подключить собственный Claude-софт для распознавания/транскрипции» (свои ключи/токены) — отдельная будущая фаза. Когда она появится, отправка каких-либо данных наружу будет **явным opt-in** пользователя с указанием, что и куда уходит. Под безопасное хранение таких ключей в коде оставлен keychain-seam (значения — только в системном Keychain, никогда в БД или логах). В текущей сборке этот путь не активирован.

## Биометрия (Voice Samples)

Если пользователь явно включил «Запоминать голос» для контакта (C2 паспорта), Wotold вычисляет voice embedding из сегмента аудио и сохраняет в локальную БД. Это:

- Не передаётся никуда за пределы устройства.
- Используется только для подсказок «возможно это Иван» при следующих звонках.
- Финальная привязка к контакту — всегда явное подтверждение пользователем (R2 паспорта).
- Удалить можно через UI: контакт → редактировать → «Голосовые семплы» → ✕ на конкретном семпле.

## Права пользователя

В соответствии с GDPR Art. 13–17:

- **Доступ к данным** — все данные открыты в UI приложения. Сырые WAV и `app.db` доступны в `~/Library/Application Support/app.wotold.desktop/`.
- **Удаление** — UI «Удалить звонок» каскадно удаляет аудио + записи в БД + voice samples этого звонка. UI «Удалить контакт» каскадно убирает все семплы этого контакта.
- **Отзыв согласия** — снять галку «Запоминать голос» в карточке контакта. Существующие семплы удаляются при ручном клике.
- **Экспорт** — recap и transcript хранятся как Markdown в `calls/<id>/` — можно скопировать вручную.
- **Wipe всех данных** — удалить директорию `~/Library/Application Support/app.wotold.desktop/` (или через Settings → Конфиденциальность → «Удалить все данные» — _в разработке_).

## Безопасность

- TLS на скачивании моделей с HuggingFace; целостность скачанных моделей проверяется по SHA256.
- Обработка звонков — офлайн, без сетевых вызовов.
- Секреты будущих внешних интеграций — только в системном Keychain, никогда в БД и логах.
- MCP-сервер — read-only, без сетевых вызовов; контент звонков рассматривается как недоверенные данные (защита от инъекций инструкций).
