# Политика конфиденциальности — Wotold

_Версия: 0.1 (pre-MVP, 2026-05-20)_

Wotold — десктоп-приложение для локальной записи звонков с транскрипцией и саммари. Этот документ описывает, какие данные мы обрабатываем, где они хранятся, и какие права есть у пользователя. Документ заменит/дополнится в момент первого публичного релиза.

## TL;DR

- Аудио, транскрипты, контакты — хранятся **только локально** на устройстве пользователя.
- Прокси (Cloudflare Worker) видит **только** метрики использования по обезличенному `device-id` (UUID v4) и временно — аудиофайл во время STT-обработки.
- Партнёры (Soniox, Gladia, Groq) обрабатывают аудио и транскрипт ради своей услуги. Их политики применяются дополнительно.
- Биометрические данные (voice samples / embeddings) — **только с явного opt-in** для каждого контакта и без передачи на сервер.
- Управление данными — полностью в UI приложения: удалить контакт, удалить звонок (каскадно с аудио и семплами), отозвать согласия.

## Какие данные мы собираем

| Категория | Где хранится | Что внутри | TTL |
|---|---|---|---|
| Аудиозаписи (`*.wav`) | `~/Library/Application Support/app.wotold.desktop/calls/<id>/` | Микрофон + системное аудио, raw PCM | Пока пользователь не удалит |
| База данных (`app.db`) | то же | Метаданные звонков, контакты, расшифровки, action_items, voice samples (если opt-in) | то же |
| Сессионные токены OIDC | macOS Keychain | Bearer для аутентификации в прокси | 30 дней (server TTL) |
| BYO API ключи | macOS Keychain | Soniox / Gladia / Anthropic — если пользователь подключил свои | Пока пользователь не удалит |
| `device-id` | `~/Library/Application Support/app.wotold.desktop/device.txt` | Случайный UUID v4 | Пока пользователь не переустановит |

## Какие данные передаются наружу

### 1. На прокси Wotold (Cloudflare Worker)

- `device-id` (UUID v4) — для квоты по дневному лимиту.
- Аудиофайл — **временно** загружается в R2 staging (с pre-signed URL), STT-партнёр забирает по ссылке, мы удаляем. Worker сам аудио в памяти **не держит** (R8 паспорта).
- Транскрипт (если включён managed LLM) — передаётся в Groq для генерации саммари. Удаляется после ответа.

Прокси НЕ сохраняет аудио, транскрипты, контакты. Логи — только статусы запросов без содержимого.

### 2. STT-провайдеры (Soniox primary, Gladia fallback)

Аудио передаётся для распознавания речи. Провайдеры имеют свои политики:
- Soniox: https://soniox.com/privacy
- Gladia: https://www.gladia.io/privacy

### 3. LLM-провайдер (Groq в managed, Anthropic в BYO)

Транскрипт передаётся для генерации саммари. Имена контактов из локальной базы добавляются как контекст (если confirmed). Провайдеры:
- Groq: https://groq.com/privacy-policy
- Anthropic: https://www.anthropic.com/privacy

### 4. Идентификация (OIDC)

Если пользователь подключает Google аккаунт — прокси получает только `sub` (provider user id), `email`, `displayName`. Никаких других claims не запрашиваем (scope `openid email profile`).

## Биометрия (Voice Samples)

Если пользователь явно включил «Запоминать голос» для контакта (C2 паспорта), Wotold вычисляет 256-мерный voice embedding из сегмента аудио и сохраняет в БД. Это:
- Не передаётся на сервер.
- Используется только для подсказок «возможно это Иван» при следующих звонках.
- Финальная привязка к контакту — всегда явное подтверждение пользователем (R2 паспорта).
- Удалить можно через UI: контакт → редактировать → «Голосовые семплы» → ✕ на конкретном семпле.

## Права пользователя

В соответствии с GDPR Art. 13–17:

- **Доступ к данным** — все данные открыты в UI приложения. Сырые WAV и `app.db` доступны в `~/Library/Application Support/app.wotold.desktop/`.
- **Удаление** — UI «Удалить звонок» каскадно удаляет аудио + записи в БД + voice samples этого звонка. UI «Удалить контакт» каскадно убирает все семплы этого контакта.
- **Отзыв согласия** — снять галку «Запоминать голос» в карточке контакта. Существующие семплы удаляются при ручном клике.
- **Экспорт** — recap и transcript хранятся как Markdown в `calls/<id>/` — можно скопировать вручную.
- **Wipe всех данных** — удалить директорию `~/Library/Application Support/app.wotold.desktop/` (или через Settings → Конфиденциальность → «Удалить все данные» — _в разработке_).

## Безопасность

- TLS на всех сетевых вызовах.
- Pre-signed URL для R2 — короткий TTL (15 минут), single-use HEAD-check.
- API-ключи — только в Keychain, никогда в БД и логах.
- Аудио в R2 удаляется после успешного STT (life-cycle policy).

## Контакты
