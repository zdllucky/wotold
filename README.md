A desktop call recorder with transcription, speaker diarization and summaries — **running entirely on your Mac, free, offline**.

Website: **[zdllucky.github.io/wotold](https://zdllucky.github.io/wotold/)** — install guide, features, privacy, FAQ.

**Status:** local-only. The core works end to end: record → local STT → diarization → summary → RAG assistant over your calls. Everything is computed on-device (macOS). The local engine — whisper.cpp + sherpa-onnx diarization + llama.cpp — is the only processing path.

Full spec and architecture: [`docs/ПАСПОРТ_ПРОЕКТА.md`](docs/ПАСПОРТ_ПРОЕКТА.md) (Russian).

## Why Wotold

- **Local-first, and local-only.** Recording, transcription, diarization, summarization and search all happen on your machine. No network, no subscription, no audio leaving the device. The single network flow in the entire product is the one-time model download from Hugging Face.
- **Speaker diarization.** The transcript is split by speaker rather than dumped as a wall of text — which is what makes recaps and search actually useful. This is the gap that motivated the project: existing tools transcribe, but do not tell you who said what.
- **Voice fingerprints.** Wotold suggests "this might be Ivan" based on voice samples from your address book. Binding a speaker to a contact **always** requires your explicit confirmation — never automatic (restriction R2).
- **RAG assistant over your calls.** A local chat assistant answers questions across your whole call archive (hybrid FTS5 + semantic embedding retrieval, answers generated by a local LLM), citing specific transcript fragments.
- **MCP server for Claude.** A local read-only MCP server gives Claude direct access to your transcripts — search, citation and Q&A without copy-paste.

Privacy documentation: [`docs/PRIVACY.md`](docs/PRIVACY.md).

## Install

1. **Download** the latest `.dmg` from [Releases](https://github.com/zdllucky/wotold/releases). Requires **macOS 14+**.
2. **Open** the DMG and drag Wotold into Applications.
3. **First launch.** The build is not notarized (deliberate MVP limitation, R6), so Gatekeeper will warn you. Go to System Settings → Privacy & Security → "Open anyway".
4. **Onboarding.** Wotold asks for your name and role (so it knows who speaks on your track), plus Microphone and Screen Recording permissions. Wotold does **not** capture screenshots — ScreenCaptureKit is used only to obtain system audio.
5. **Models.** On first use Wotold downloads local models (~2–7 GB depending on the Light / Balanced / Quality preset) from Hugging Face. Downloaded once, offline afterwards.
6. **Record.** Press "Start recording" (or ⌘⇧R), then "Stop". Local processing begins; on a long call local STT plus LLM summarization takes minutes, with progress shown in the UI.

Detailed guide: [zdllucky.github.io/wotold/download](https://zdllucky.github.io/wotold/download/).

### What Wotold does not do

- Does not store audio or transcripts on servers — there are none. Everything lives in `~/Library/Application Support/app.wotold.desktop/`.
- Does not assign speakers to contacts automatically — that is always your explicit confirmation (R2).
- Does not record the screen. System audio comes through the ScreenCaptureKit API, but no frames are kept.
- Does not make network calls while processing, apart from the initial model download.

## Development

Requirements:

- **macOS** 14.2+ — Core Audio process tap; the local engine is macOS-only in the MVP (R9)
- **Node.js** ≥ 20.18 (see `.nvmrc`)
- **pnpm** ≥ 10
- **Rust** stable + Tauri CLI 2 (`cargo install tauri-cli --version "^2"`)

```bash
git clone https://github.com/zdllucky/wotold.git
cd wotold
pnpm install

# Desktop app
pnpm tauri dev

# Local MCP server
pnpm --filter @wotold/mcp dev

# Website
pnpm --filter @wotold/site dev
```

Tests:

```bash
# Rust core
cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml

# TypeScript workspaces
pnpm -r test
```

Read [`CONTRIBUTING.md`](CONTRIBUTING.md) before opening a pull request — this repository enforces a design gate for UI changes, test-first development for algorithmic modules, conventional commits, and coverage ratchets.
