# Wotold

Десктоп-утилита для записи звонков с транскрипцией, диаризацией и саммари — **полностью на твоём Mac, бесплатно навсегда**. Опциональный облачный режим для лучшего качества.

**Статус:** pre-MVP, активная разработка. M12 local-engine pivot — [`docs/M12_LOCAL_ENGINE_PRD.md`](docs/M12_LOCAL_ENGINE_PRD.md).

ТЗ и архитектура: [`docs/ПАСПОРТ_ПРОЕКТА.md`](docs/ПАСПОРТ_ПРОЕКТА.md).

## Чем Wotold отличается

- **Local-first.** Default-движок (M12) — sherpa-onnx Whisper + llama.cpp прямо на устройстве. Без сети, без подписки, без отправки аудио кому-либо.
- **Без квоты на free-тире.** Местный движок не ограничен — записывай хоть весь рабочий день.
- **Cloud — опция, не требование.** Если нужно лучшее качество саммари — переключайся на Cloud Pro в Settings. Свои ключи (BYO Soniox/Anthropic) — тоже поддерживаются.
- **Privacy-сегмент.** Юристы, врачи, безопасники — аудио не покидает Mac. Privacy-документация: [`docs/PRIVACY.md`](docs/PRIVACY.md).
- **MCP для Claude.** Локальный MCP сервер даёт LLM прямой доступ к транскриптам — поиск, цитирование, саммари без копи-паста.

## Для пользователя

1. **Скачать** последний `.dmg` из [Releases](https://github.com/zdllucky/wotold/releases) (нужен macOS 14+).
2. **Открыть** DMG → перетащить Wotold в Applications.
3. **Первый запуск.** Gatekeeper выдаст предупреждение (сборка пока без нотаризации — см. R6 паспорта). Открой Системные Настройки → Конфиденциальность и Безопасность → «Открыть всё равно».
4. **Onboarding.** Wotold попросит:
   - **Имя и роль** — чтобы знать «кто говорит» на твоей дорожке.
   - **Микрофон + Запись экрана** — для записи. Wotold НЕ делает скриншоты, ScreenCaptureKit используется только для системного аудио.
5. **Настройка движка (M12.5).** В Settings → «Движок распознавания» выбери: Local (default), Cloud Wotold (Pro), или свои ключи провайдеров. Local скачает модели (~2-7 GB в зависимости от preset'а Light/Balanced/Quality) при первом включении.
6. **Запись.** На главной нажми «Начать запись» (или ⌘⇧R). По завершении нажми «Стоп» — через 10–30 секунд появится саммари в виде MoM.

### Что Wotold НЕ делает

- Не сохраняет аудио и транскрипты на наших серверах. Всё хранится локально в `~/Library/Application Support/app.wotold.desktop/`.
- Не присваивает спикеров контактам автоматически — это всегда твоё явное подтверждение (R2 паспорта).
- Не записывает экран. Системное аудио берётся через ScreenCaptureKit API, но кадры не сохраняются.
- В Local-режиме — не делает никаких сетевых вызовов (кроме первичного скачивания моделей с HuggingFace).

### Если что-то не работает

- **Local-движок ещё не активирован** — `failed_reason: local_engine_not_yet_wired`. Реальный sherpa-onnx + llama.cpp wire-up ждёт PRD §14 pre-flight gate (SHA256 + sherpa version pin + llama O2 decision). До тех пор переключись на Cloud Wotold в Settings → Движок.
- **Cloud STT не получилось** — нажми «Попробовать ещё раз» в банере звонка. Иногда Soniox/Gladia флапают, auto-fallback переключает.
- **Recap failed (cloud)** — отдельный банер с retry. LLM (Groq llama-3.3-70b на free-тире) может ratelimit или 5xx.
- **Превышен лимит cloud** — дневная квота на бесплатном Cloud-тире. Подожди до полуночи UTC либо переключись на Local (без квот) или подключи свои ключи в Настройках.

### Конфиденциальность

| Режим | Куда уходит аудио | Куда уходит транскрипт |
|---|---|---|
| **Local** (default) | никуда | никуда |
| **Cloud Managed (Pro)** | временно в R2 staging + STT-партнёр, затем удаляется | LLM-провайдер (Groq/Anthropic) |
| **Cloud BYO** | твой STT-партнёр напрямую | твой LLM-партнёр напрямую |

В Local-режиме единственный сетевой вызов — первое скачивание моделей с `huggingface.co`. БД (`app.db`) и аудио всегда локальные. Удалить контакт = каскадное удаление voice samples (C5 паспорта).

Полная политика — [`docs/PRIVACY.md`](docs/PRIVACY.md).

## Что внутри

Монорепо:

| Путь | Что |
|---|---|
| `apps/desktop/` | Tauri 2 приложение (фронт TS + Rust + Swift sidecar Core Audio) |
| `services/proxy/` | Hono на Cloudflare Workers — relay STT/LLM, квота по device-id |
| `services/mcp/` | Локальный MCP-сервер (read-only) для подключения в Claude |
| `packages/contracts/` | Общие типы между приложением и прокси |

## Требования

- Node.js ≥ 20.18
- pnpm ≥ 10
- Rust stable + Tauri CLI 2 (`cargo install tauri-cli --version "^2"`)
- macOS 14.2+ для разработки/запуска приложения (Core Audio process tap)

## Подпись обновлений (M11)

Tauri-ключ minisign генерируется один раз:

```bash
pnpm --filter @wotold/desktop exec tauri signer generate -w ~/wotold-tauri-signing.key
```

Результат:

1. **Публичный ключ** → подставить в `apps/desktop/src-tauri/tauri.conf.json` → `plugins.updater.pubkey`. Коммитится в репозиторий.
2. **Приватный ключ** + пароль → положить в GitHub-секреты репозитория:
   - `TAURI_SIGNING_PRIVATE_KEY` — содержимое файла
   - `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` — пароль с генерации
3. **Офлайн-бэкап** приватного ключа (зашифрованный архив на внешний носитель).

> ⚠️ **Потеря приватного ключа = невозможность доставлять обновления существующим установкам.** Новый ключ потребует переустановки всех клиентов. Хранить дисциплинированно. См. M11.9 паспорта.

### Аварийный откат релиза (M11.8)

В UI downgrade не выставлен. Для отката плохого релиза:

1. Опубликовать `vX.Y.Z+1` с кодом из последней рабочей версии (рекомендуемый путь).
2. Если форс-маж: запустить клиент с `WOTOLD_UPDATER_ALLOW_DOWNGRADE=1` — `default_version_comparator` примет любую версию из манифеста, не равную текущей.

## Первый запуск на macOS

В MVP сборка не нотаризована (R6 паспорта). При первом запуске Gatekeeper потребует разрешения через Системные Настройки → Конфиденциальность и Безопасность → «Открыть всё равно».
