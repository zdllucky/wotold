# Wotold

Десктоп-утилита для записи звонков с транскрипцией, диаризацией и саммари — **полностью на твоём Mac, бесплатно, без сети**.

**Статус:** local-only. Ядро работает end-to-end: запись → локальный STT → диаризация → саммари → RAG-ассистент по звонкам — всё считается на устройстве (macOS). Локальный движок (whisper.cpp + sherpa-onnx диаризация + llama.cpp) — единственный путь обработки.

ТЗ и архитектура: [`docs/ПАСПОРТ_ПРОЕКТА.md`](docs/ПАСПОРТ_ПРОЕКТА.md).

## Чем Wotold отличается

- **Local-first.** Запись, транскрипция, диаризация, саммари и поиск — на устройстве. Без сети, без подписки, без отправки аудио кому-либо. Единственный сетевой поток — первичное скачивание моделей с HuggingFace.
- **Диаризация.** Транскрипт не сплошным текстом, а с разделением спикеров — рекапы и поиск становятся осмысленными.
- **Голосовые отпечатки.** Wotold подсказывает «возможно это Иван» по голосу из адресной книги. Привязка к контакту — всегда только с твоего явного подтверждения (R2 паспорта), никакой автопривязки.
- **RAG-ассистент по звонкам.** Локальный чат-ассистент отвечает на вопросы по всей базе звонков (гибридный поиск FTS5 + семантические эмбеддинги, ответы генерирует local-LLM) — с ссылками на конкретные фрагменты транскрипта.
- **MCP для Claude.** Локальный read-only MCP-сервер даёт Claude прямой доступ к транскриптам — поиск, цитирование, Q&A без копи-паста.

Privacy-документация: [`docs/PRIVACY.md`](docs/PRIVACY.md).

## Для пользователя

1. **Скачать** последний `.dmg` из [Releases](https://github.com/zdllucky/wotold/releases) (нужен macOS 14+).
2. **Открыть** DMG → перетащить Wotold в Applications.
3. **Первый запуск.** Gatekeeper выдаст предупреждение (сборка пока без нотаризации — см. R6 паспорта). Открой Системные Настройки → Конфиденциальность и Безопасность → «Открыть всё равно».
4. **Onboarding.** Wotold попросит:
   - **Имя и роль** — чтобы знать «кто говорит» на твоей дорожке.
   - **Микрофон + Запись экрана** — для записи. Wotold НЕ делает скриншоты, ScreenCaptureKit используется только для системного аудио.
5. **Модели.** При первом включении Wotold скачает локальные модели (~2–7 GB в зависимости от preset'а Light/Balanced/Quality) с HuggingFace. Скачивается один раз, дальше — офлайн.
6. **Запись.** На главной нажми «Начать запись» (или ⌘⇧R). По завершении нажми «Стоп» — начнётся локальная обработка. Время зависит от длины звонка, выбранного preset'а и железа: на длинной записи локальный STT + LLM-саммари — это порядок минут (прогресс виден в UI).

### Что Wotold НЕ делает

- Не сохраняет аудио и транскрипты на серверах — их нет. Всё хранится локально в `~/Library/Application Support/app.wotold.desktop/`.
- Не присваивает спикеров контактам автоматически — это всегда твоё явное подтверждение (R2 паспорта).
- Не записывает экран. Системное аудио берётся через ScreenCaptureKit API, но кадры не сохраняются.
- Не делает сетевых вызовов при обработке — кроме первичного скачивания моделей с HuggingFace.

### Если что-то не работает

- **Обработка идёт долго** — это ожидаемо на длинных записях: локальный STT и LLM-саммари считаются на CPU/GPU устройства. Прогресс отображается в карточке звонка. Более лёгкий preset (Light) заметно быстрее за счёт качества.
- **Модель не скачалась** — проверь сеть и свободное место на диске, затем повтори скачивание в Настройках → «Обработка». До появления моделей звонок останется в очереди.
- **Саммари пустое или слабое** — качество local-LLM саммари ниже облачного (R12 паспорта), UI показывает уровень качества движка. Рекап можно перегенерировать без повторной транскрипции (используется сохранённый STT-результат).
- **Звонок завис в «ошибке» после краша** — Wotold умеет восстанавливать прерванную обработку при следующем старте, если аудио на диске цело (B28 в ROADMAP).

### Конфиденциальность

Всё локально. Аудио (`*.wav`), база (`app.db`), транскрипты и рекапы (`*.md`) живут только в `~/Library/Application Support/app.wotold.desktop/` и никуда не уходят. Единственный сетевой вызов — первое скачивание моделей с `huggingface.co`. Голосовые отпечатки (voice samples) — opt-in по каждому контакту, хранятся только локально. Удалить контакт = каскадное удаление его voice samples (C5 паспорта).

Полная политика — [`docs/PRIVACY.md`](docs/PRIVACY.md).

> Внешние интеграции (например, подключение собственного Claude-коннектора со своими ключами для распознавания/транскрипции) — планируются отдельной опциональной фазой. Под них в коде оставлен generic keychain-seam; в текущей сборке никакие внешние API не задействованы.

## Что внутри

Монорепо:

| Путь | Что |
|---|---|
| `apps/desktop/` | Tauri 2 приложение (фронт TS + Rust ядро + Swift sidecar Core Audio) |
| `services/mcp/` | Локальный MCP-сервер (read-only) для подключения в Claude |
| `packages/contracts/` | Общие типы (DiarizedTranscript, рекап-JSON, `latest.json`) |

## Development

Требования:

- **macOS** 14.2+ (Core Audio process tap; локальный движок в MVP — только macOS, R9 паспорта)
- **Node.js** ≥ 20.18
- **pnpm** ≥ 10
- **Rust** stable + Tauri CLI 2 (`cargo install tauri-cli --version "^2"`)

Установка и запуск:

```bash
git clone https://github.com/zdllucky/wotold.git
cd wotold
pnpm install

# Desktop-приложение (Tauri dev)
pnpm tauri dev

# Локальный MCP-сервер
pnpm --filter @wotold/mcp dev
```

Тесты:

```bash
# Rust-ядро
cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml

# TypeScript-воркспейсы (desktop + mcp)
pnpm -r test
```

## Подпись обновлений (M11)

Tauri-ключ minisign генерируется один раз:

```bash
pnpm --filter @wotold/desktop exec tauri signer generate -w ~/wotold-tauri-signing.key
```

Результат:

1. **Публичный ключ** → подставить в `apps/desktop/src-tauri/tauri.conf.json` → `plugins.updater.pubkey`. Коммитится в репозиторий.
2. **Приватный ключ** + пароль → положить в GitHub-секреты репозитория:
   - `TAURI_SIGNING_PRIVATE_KEY` — содержимое файла
   - `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` — пароль с генерации
3. **Офлайн-бэкап** приватного ключа (зашифрованный архив на внешний носитель).

> ⚠️ **Потеря приватного ключа = невозможность доставлять обновления существующим установкам.** Новый ключ потребует переустановки всех клиентов. Хранить дисциплинированно. См. M11.9 паспорта.

### Аварийный откат релиза (M11.8)

В UI downgrade не выставлен. Для отката плохого релиза:

1. Опубликовать `vX.Y.Z+1` с кодом из последней рабочей версии (рекомендуемый путь).
2. Если форс-маж: запустить клиент с `WOTOLD_UPDATER_ALLOW_DOWNGRADE=1` — `default_version_comparator` примет любую версию из манифеста, не равную текущей.

## Первый запуск на macOS

В MVP сборка не нотаризована (R6 паспорта). При первом запуске Gatekeeper потребует разрешения через Системные Настройки → Конфиденциальность и Безопасность → «Открыть всё равно».
